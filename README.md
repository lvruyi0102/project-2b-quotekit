# QuoteKit

Phase-1 asset for Project 2B. A single-file commercial quote generator for freelancers and small studios.

This repository does not claim customers, revenue, or sales. Income is recorded only after settlement.

## Use

Open `index.html` in a browser. Fill the form. Export or print to PDF.
